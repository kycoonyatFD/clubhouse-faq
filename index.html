1. Password Reset — “Details Don't Match”
▼
  1. Use DOB: 01/01/1901
  2. Try SSN: 9999 first
  3. If that fails, try SSN: 1111
  4. If still failing, DM the user a manual password reset link
The password can be set to anything once the reset link is accessed.
2. Password Reset Email Not Received
▼
  1. Confirm user is entering their +fdclubhouse email — firstname.lastname+fdclubhouse@fanduel.com
  2. Check the accounts spreadsheet — if not listed, account not yet provisioned
  3. If not in spreadsheet, request via the ARB:
    • Access Request System: Runway
    • Permission Level: Runway - Clubhouse
  4. If in spreadsheet but no email: check for name changes (married vs maiden). Email can be updated to match
  5. As a workaround, generate and DM a direct password reset link
3. Account Not Yet Provisioned / No Account
▼

To request an account, create a ticket on the ARB, asking for:

  • Access Request System: Runway
  • Permission Level: Runway - Clubhouse

This will generate an account for the user.

4. Location Verification Failed — Web
▼
  1. If account is brand new — may not be GeoComply-whitelisted yet. Whitelisting happens in batches on Fridays. Wait until the next Friday if less than one Friday has passed since hire.
  2. Disconnect from GlobalProtect VPN — web version requires no VPN
  3. Check Netskope — confirm “Private Access” is enabled
  4. Clear browser cache and cookies, then reload
  5. If still failing, try a different browser
  6. If issue persists and appears non-user-error, raise via #sportsbook-support
If outside the US, try routing traffic via VPN from a US server.
5. Location Verification Failed — Mobile App
▼
  1. If account is brand new — GeoComply whitelisting happens in batches on Fridays. Ask them to wait if less than one Friday has passed since hire.
  2. Confirm user is logged in with their +fdclubhouse account, not their regular FanDuel account
  3. Check app location permissions: iOS → Settings → find the app → Location → set to Always
  4. If permissions were previously denied, delete and reinstall — allow location on first launch
6. iOS “Untrusted Developer” Error
▼
  1. Go to Settings → General → VPN & Device Management → FanDuel Inc.
  2. Tap “Trust Developer”
  3. Restart the phone when prompted
  4. App should work after restart
7. Okta / FastPass Not Working on Phone
▼
  1. Open Okta Verify → tap “Launch Dashboard”
  2. Scroll to bottom → find Runway → tap it
  3. Log in with your regular @fanduel.com email
  4. If Runway fails and redirects back to Okta Verify setup, the issue is with Okta FastPass — outside Clubhouse scope. File an IT ticket via Jarvis: “Need help configuring Okta FastPass on my device”
No Runway on Okta? Atlassian Service Desk → Access Request Board → Common Requests → Access Request → System: Runway → Permission: Runway - Clubhouse.
8. MFA / Verification Code Prompt on New Device
▼

MFA is turned off by default. It only triggers as a new device challenge when first logging in to a new build.

  1. When prompted, select the “Email” option at the bottom — text and authenticator options will not work
  2. The code email may arrive in the “Other” folder — check there if not in the main inbox
9. “Linked Account” / Duplicate Account Error
▼
  1. Confirm the exact email being used (firstname.lastname+fdclubhouse@fanduel.com)
  2. A CS agent with admin access needs to remove the duplicate — escalate to a senior agent/admin if you don't have that access
10. Account Suspended
▼

Have the user email fdgcomplianceops@fanduel.com to resolve the suspension.

11. 403 Error Accessing the Website
▼
  1. Check Netskope — ensure “Private Access” is enabled
  2. Make sure you are not on GlobalProtect VPN
  3. Try an incognito/private window
  4. If issue persists, try the mobile app and open an EITSD ticket for the web access issue
12. Bets Not Appearing in “My Bets”
▼
  1. Check Transaction History — if deduction is there, bet was placed and issue is display-only
  2. Note the Bet Reference number (format: fd:01jw...)
  3. Reassure the user: their balance is correct even if the bet doesn't display
  4. If widespread or not user error, raise via #sportsbook-support or get IT-Ops to help find an owner
13. Leaderboard Balance Doesn't Match Account Balance
▼

Leaderboards throughout the contest are always directional and never final. The final leaderboard is published 1 day after the contest ends.

  1. Reassure the user: whatever they see on their app is what will count
  2. If the balance appears wrong after the final leaderboard has been published, escalate to Eric Milam or Ky Coony — do not contact them before the final leaderboard is out
14. “This Service Is Unavailable” on Login
▼

Typically means the user is logging in with the wrong email on the wrong app.

  1. Confirm the user is using their +fdclubhouse email on the Clubhouse app
  2. Confirm they are not using Clubhouse credentials on the regular FanDuel Sportsbook app
15. No Balance / Funds in Account
▼

When a contest starts, users receive bonus bets, not cash — they must be toggled on, not auto-applied.

  1. Go to the Rewards section in the app
  2. Add a selection to the betslip
  3. Toggle on the bonus bet from the betslip to apply it
Bonus bets must “win” to convert to cash. Only net winnings carry over — the stake is not returned.

  1. The user needs to download a new build
  2. Settings → General → VPN & Device Management → FanDuel Inc. → Delete App
  3. Re-follow the Runway download guide to install the latest build (canvas at top of #internal-contests)
17. White Screen on App — Won't Load
▼
  1. Delete and redownload the app.
18. “Waiting for Tipoff” Loading Screen Stuck
▼
  1. Close the app completely and relaunch.
19. “No Funds Deducted” Error When Placing a Bet
▼

The contest has not started yet. Check #internal-contests to confirm the start date — the user may be trying to bet before the contest window opens.

What is Clubhouse?
FanDuel Clubhouse is the company's internal contest platform — a fully legal, compliant sportsbook environment for employees to deepen product knowledge, provide feedback, and compete for prizes while experiencing the sportsbook from the inside.
Employee Eligibility
Available to all full-time FanDuel employees 21+ under permanent or fixed-term agreements in: US, Canada, UK, Porto (Tech/Product/Data/Enterprise), Dublin (FanDuel-specific job titles), and Australia. US employees on a state gambling exclusion list are not eligible.
Compliance Rules
⚠️ Employee Play Policy — Must Follow
  • Bets must be placed using a Clubhouse account only
  • Winnings may NOT be withdrawn
  • Personal funds may NOT be deposited
  • Funds from other FanDuel accounts may NOT be transferred to Clubhouse
  • Clubhouse login may NOT be used on other FanDuel products
  • Violations may result in disciplinary action
Contest Period & Entry
Announced via #internal-contests and in the Promotions Carousel. Eligible employees are automatically issued site credit and/or Bonus Bets at contest start. Additional generosity may include Profit Boost Tokens, Boost Builder Tokens, and No Sweat Tokens (valid for cash wagers only).
Leaderboards
🏆 Largest Final Cash Balance
Largest overall cash balance at end of Contest Period, regardless of wager type or stake.
🎯 Biggest Odds on a Winning Single Wager
Biggest odds on a winning Single Wager (moneyline, spread, over/under, player props — no parlays/futures) with stake ≥ $1.00. Must settle to completion, no cashouts.
💰 Biggest Return on Investment (Single Wager)
Biggest net winnings (total payout minus initial stake) on a winning Single Wager with stake ≥ $1.00.
📊 YourWay Leaderboard
Most cumulative money earned betting via the YourWay tab. All YourWay winnings summed at contest end.

Bonus Bets & Tokens
Bonus Bets▼

A risk-free wager that must “win” to convert to cash. Only net winnings are kept — stake not returned. Example: $100 bonus at -200 odds → win = $50 cash. Leaderboards track cash balance only.

Profit Boost Tokens (PBT)▼

Boost odds by a set %. Example: +393 + 30% PBT = +510. Toggle on betslip. Cash bets only.

Boost Builder Tokens (BBT)▼

Boost parlay odds. 3-leg = +15%; each additional leg (up to 12) adds 10pp. Cash bets only.

Access & Setup
What is Clubhouse? ▼
FanDuel Clubhouse is the company's internal contest platform — a 100% legal, compliant sportsbook environment for employees to deepen product knowledge, provide feedback, and compete for prizes.
How do I join Clubhouse? ▼
Accounts are provisioned automatically via HRIS/Okta sync during onboarding. If not provisioned, create a ticket on the ARB: Access Request System: Runway, Permission Level: Runway - Clubhouse.
What will my Clubhouse email look like? ▼
US/UK/Porto: firstname.lastname+fdclubhouse@fanduel.com · Dublin: firstname.lastname+fdclubhouse@ppb.com · Australia: firstname.lastname+fdclubhouse@sportsbet.com.au. Check the accounts spreadsheet if unsure.
How do I log in for the first time? ▼
Go to clubhouse.sportsbook.fanduel.com → “Forgot your password?” → enter your +fdclubhouse email → check your normal FanDuel work inbox for the reset email → click the link → set a new password. When prompted for DOB and SSN, use DOB: 01/01/1901 and SSN: 9999.
I get “You do not have permission to view this content” on Runway. ▼
Request access via the ARB:

• Access Request System: Runway
• Permission Level: Runway - Clubhouse
I don't have Runway on my Okta. ▼
Create a ticket on the ARB: Access Request System: Runway, Permission Level: Runway - Clubhouse. Granted within a few days pending manager approval.
Compliance & Restrictions
Can I withdraw or deposit funds? ▼
No. Both are against the employee play policy. Balances are cleared between contests.
Can I use my Clubhouse login on other FanDuel products? ▼
No. Against the employee play policy. Security rules block cross-product login in both directions.
Are there country restrictions? ▼
Yes — Clubhouse cannot be used in Romania due to local laws. If you get a 404 or blank page from another country, try a VPN routed from the US.
Are markets limited on Clubhouse? ▼
No — the experience mirrors customers'. New features may be tested on Clubhouse first. Market feedback goes to #clubhouse-product-feedback.
Contests & Prizes
How do Clubhouse contests work? ▼
1. Contest announced in #internal-contests and via email. 2. Contest funds auto-added at start. 3. Wager using funds, promos, and winnings. 4. Leaderboard determines winners. 5. Results in #internal-contests. Awards via Spotlight (US/UK/CA) or HR (Dublin/Porto/AUS).
How often do contests run? How long do they last? ▼
~Once a month, around major sporting events. Most run ~1 week. Always check #internal-contests for exact dates.
What prizes can I win? When will I get them? ▼
Prizes distributed within 30 days via Spotlight (US/UK/CA), FanDuel AU Rewards (AUS), or Flutter Kudos (Dublin/Porto).
I accidentally used all my bonus bets. Can I get more? ▼
No — we cannot void wagers or add more funds. Bonus bets are not eligible for cashouts.
I received a message saying my winnings were taken out. Why? ▼
Clubhouse balances are cleared at the end of each contest — expected behaviour.
